The workflow

Every output has
a source story.

PartSmith keeps the evidence connected to the engineering decisions. Generated files are checked together before a separate release approval.

Evidence first. Review always.

  1. Start with the source

    Choose manufacturer documentation and the exact component ordering number.

  2. Review the engineering inputs

    Inspect extracted evidence, resolve missing facts, and approve component data and package definitions.

  3. Generate and validate

    Build symbols, footprints, and 3D models independently, then check their dimensions and relationships.

  4. Approve the exact release

    Review the retained artifacts and validation results before releasing a component bundle for library installation.

A few details

Before you start.

Which platform is the current target?

The current candidate targets Windows AMD64 and KiCad 10.0.6, using KiCad's bundled Python. See the installation guide for the exact supported setup.

Does installation require internet access?

Yes. KiCad prepares the plugin's Python dependencies online. Installation, dependency updates, and environment recreation require internet access. Local processing is available after successful setup.

What needs to be installed manually?

OCR needs Tesseract 5 with English, German, and Simplified Chinese language data. PartSmith checks these at startup and provides installation links if anything is missing.
