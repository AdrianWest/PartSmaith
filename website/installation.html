Installation guide · Development candidate

Prepare PartSmith
for KiCad.

The current candidate targets Windows AMD64 and KiCad 10.0.6. The first public production release is not available yet. These steps describe preparing a candidate PCM package for testing.

  1. Check your KiCad setup

    Use KiCad 10.0.6 and its bundled Python 3.11. In KiCad's Python/IPC preferences, select the bundled interpreter and enable the PCB Editor API. On a standard Windows installation, the interpreter is C:/Program Files/KiCad/10.0/bin/python.exe. Customer installation does not need a separate Python installation.

  2. Install the OCR prerequisites

    Install Tesseract 5 for Windows (64-bit) with English (eng), German (deu), and Simplified Chinese (chi_sim) language data. KiCad's Python package installer does not install this standalone OCR engine.

  3. Install the PCM package

    Use a PartSmith PCM ZIP supplied for your test build. In the KiCad project manager, open Plugin and Content Manager, choose Install from File, and select that ZIP. Public production packages will be listed on the releases page when available.

  4. Wait for environment preparation

    KiCad downloads and installs PartSmith's Python dependencies in a private plugin environment. Installation, dependency updates, and environment recreation require internet access. Wait for preparation to finish; reload or restart the PCB Editor if needed for plugin registration. Local processing is available after successful preparation.

  5. Open PartSmith

    Use the Open PartSmith IPC toolbar action in the PCB Editor. Startup checks the runtime and manual OCR prerequisites before opening setup. Missing OCR items show an error with installation links. PCB inspection is a separate, deliberate action through Inspect PCB....

Setup help

An existing installation?

My plugin environment previously used Python 3.12.

Select KiCad's bundled Python 3.11, then right-click Open PartSmith under Preferences → PCB Editor → Plugins and choose Recreate Plugin Environment. Changing the interpreter preference alone does not migrate an existing environment. Recreation requires internet access.

Tesseract is installed, but PartSmith cannot find it.

PartSmith checks PARTSMITH_TESSERACT, then PATH, then the standard Windows Tesseract installation. A stale explicit override must be corrected. If TESSDATA_PREFIX is set, the required language data must be available in that selected folder. Correct the installation or settings, then restart PartSmith.
